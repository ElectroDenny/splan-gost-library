# splan-gost-library

Библиотека условных графических обозначений (УГО) электронных компонентов для выполнения схем по стандартам ЕСКД в программе **sPlan 8**.

На данный момент акцент сделан на выполнении электрических принципиальных схем (Э3), но при желании можно развить данную библиотеку для выполнения любых нужных вам схем по ЕСКД.

Все УГО выполнены в строгом соответствии с актуальными ГОСТами. Если вы обнаружили несоответствие стандартам, пожалуйста, создайте **Issue** с Label `не по ГОСТ`.

## Список УГО

На текущий момент выполнены следующие условные графические обозначения элементов:
- A - Устройства
  - Отладочные платы: RP Pico, WeAct Studio RP2040, Seeed Studio XIAO-RP2040, XIAO-ESP32-C3, XIAO-ESP32-C6
- AV - Устройства регулирования напряжения: модуль быстрой зарядки USB PD XPM52C
- B - Преобразователи неэлектрических величин в электрические (кроме генераторов и источников питания) или наоборот аналоговые или многоразрядные преобразователи или датчики для указания или измерения
  - Энкодер EC11
- C - Конденсаторы
  - Конденсатор
  - Конденсатор полярный
  - Конденсатор электролитический полярный
- D - Схемы интегральные, микросборки
- DD - Схема интегральные, цифровые, логические элементы
  - Шинный буффер SN74AHCT1G126
  - Силовой ключ TPS2553
  - USB-хаб USB2517
  - USB PD-контроллер CH224A
  - USB PD-контроллер CH224K
  - Расширитель GPIO PCA9555
- E - Элементы разные
- EL - Лампы осветительные
  - Лампа накаливания
- F - Разрядники, предохранители, устройства защитные
- FU - Предохранители плавкие
  - Вставка плавкая
  - Вставка плавкая (с указанием стороны, которая остаётся под напряжением) 
- G - Генераторы, источники питания, кварцевые осцилляторы
  - Кварцевый резонатор
- H - Устройства индикационные и сигнальные
  - ЖК-дисплей графический GMT169-01
- HA - Приборы звуковой сигнализации
  - Зуммер (с указанием полярности)
- HL - Приборы световой сигнализации
  - Диод светоизлучающий
  - RGB-светодиод с общим анодом
  - RGB-светодиод с общим катодом
  - Адресный светодиод WS2812B
- L - Катушки индуктивности, дроссели
  - Катушки индуктивности
  - Катушки индуктивности c ферромагнитным магнитопроводом
- M - Двигатели
  - Электродвигатель ДП-01
  - Шаговый двигатель (2 обмотки)
- R - Резисторы
  - Резистор
  - Резистор 0,05 Вт
  - Резистор 0,125 Вт
  - Резистор 0,25 Вт
  - Резистор 0,5 Вт
  - Резистор 1 Вт
  - Резистор 2 Вт
  - Резистор 5 Вт
- S - Устройства коммутационные в цепях управления, сигнализации и измерительных
- SB - Выключатели кнопочные
  - Контакт замыкающий
  - Контакт размыкающий
  - Контакт замыкающий с самовозвратом
- U - Преобразователи электрических величин в электрические, устройства связи
- UV - Преобразователи напряжения
  - Стабилизатор UMW XC6206-3.3
  - DC-DC преобразователь WeAct Studio TPS5450
  - DC-DC преобразователь WeAct Studio DCM1V03 (LGS5148)
- V - Приборы электровакуумные, полупроводниковые
- VD - Диоды
  - Диод (общее обозначение)
- VT - Транзисторы
  - Транзистор биполярный NPN-типа
  - Транзистор биполярный PNP-типа
  - Транзистор полевой с каналом типа N
  - Транзистор полевой с каналом типа Р
  - Транзистор полевой с изолированным затвором баз вывода от подложки обогащенного типа с Р-каналом
  - Транзистор полевой с изолированным затвором баз вывода от подложки обогащенного типа с N-каналом
- X - Соединения контактные
- XP - Вилки
  - Соединитель вилка
- XS - Розетки
  - Соединитель розетка
  - Соединитель USB Type-A розетка
  - Соединитель USB Type-C розетка

# Установка библиотеки

## Способ 1: через Git

Чтобы установить данную библиотеку необходимо перейти к расположению sPlan (например, C:\Program Files\sPlan 8.0\), найти в нём папку `BIBO` и склонировать в неё этот репозиторий:
```bash
cd C:\Program Files\sPlan 8.0\
cd BIBO
git clone https://github.com/ElectroDenny/splan-gost-library.git
```

## Способ 2: скачать архив

Если у вас не установлен Git, вы можете скачать библиотеку в виде ZIP-архива:

1. Перейдите на страницу репозитория: https://github.com/ElectroDenny/splan-gost-library
2. Нажмите кнопку Code → Download ZIP.
<img width="auto" height="300" alt="image" src="https://github.com/user-attachments/assets/ba6e67bb-ee74-49d0-aa85-0f1ae9954ce2" />

3. Распакуйте содержимое архива в папку BIBO вашей установки sPlan. Важно, чтобы после распаковки структура папок выглядела так:
  ```
  BIBO/
  └── splan-gost-library/
      ├── Components/
      ├── Fonts/
      ├── Forms/
      └── README.md
  ```

## Компоненты

Для того чтобы установленная библиотека появилась в sPlan необходимо перезапустить программу.

Для вставки компонента на схему откройте нужную категорию в окне выбора компонентов слева и перетащите нужный элемент на лист. Все УГО для удобства разбиты в папки по категориям в соответствии с буквенными кодами элементов по ГОСТ 2.710-81.

<img width="1168" height="1039" alt="image" src="https://github.com/user-attachments/assets/f75a9ba7-1c85-4448-aeca-3aab60b1b971" />

## Формы

Папка Forms содержит готовые формы 1, 2, 2а, выполненные в соответсвии с ГОСТ Р 2.104-2023 &laquo;Основная надпись&raquo;.

Чтобы использовать форму:
1. В sPlan выберите "Формы" → "Загрузить форму из файла"

<img width="257" height="150" alt="image" src="https://github.com/user-attachments/assets/2f90d16f-7b6a-4a80-999b-f86949efc105" />

2. Укажите нужный .sbk файл из соответствующей подпапки `sPlan80/BIBO/splan-gost-library/Forms`.
3. Настройте соотвествующий выбранному в п.2 файлу формат и ориентацию листа.

<img width="539" height="741" alt="image" src="https://github.com/user-attachments/assets/acd772f4-507a-41eb-9fbc-055cb600f4d2" />
